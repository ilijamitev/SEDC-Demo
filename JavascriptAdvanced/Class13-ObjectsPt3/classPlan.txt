2. Intro
    => OOP paradigm
    => nacin na razmisluvanje i pristapuvanje na resavanje na nekoj task
    => i so OOP i so functional ke se postigne resenie, megutoa tie drasticno ke se razlikuvaat
    => The Four pillars of OOP:
        1) Abstraction 
        2) Encapsulation 
        3) Inheritance
        4) Polymorphism

    => JavaScript was not built with OOP in mind
    => Objects, prototypes and constructor functions were the way to use OOP in the past
    => From ES6 forward we have new features specifically designed with OOP in mind
